# Ludo

A classic, minimal web-based **Ludo** board game built with pure HTML5, CSS3, and JavaScript.

## ✨ Features

- **Classic 11×11 Board**: Authentic traditional vector board with 36 track fields, corner bases, and 4-space home lanes.
- **3D Interactive Dice**: Realistic 3D rolling dice (click or press `Space` / `Enter`).
- **Smart AI & Multiplayer**: Play with 2–4 players (Human or Bot).
- **Speed Control**: Adjust bot speed from Slow to Instant.
- **Zero Sound & Clutter**: Distraction-free, minimal interface.

## 📜 Basic Rules

1. Roll a **6** to bring a piece out of base.
2. Get **up to 3 rolls** if all your pieces are in the base.
3. Every **6** grants an **extra roll**.
4. Land on an opponent's piece to **capture** it and send it back to base.
5. First player to bring all **4 pieces into the home lane** wins!

## 🎮 Controls

- **Roll Dice**: Click button, click 3D dice, or press `Space` / `Enter`.
- **Move Piece**: Click on any highlighted piece.

## 🚀 How to Run

Simply open `index.html` in any modern web browser.
